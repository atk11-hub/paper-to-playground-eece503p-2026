# Paper to Playground

Reusable Python 3.11 agent for generating an offline, interactive explanation of a focused research-paper concept.

## Setup

```bash
python -m pip install -r requirements.txt
export OPENROUTER_API_KEY="your-key-here"
python agent.py --input examples/attention/case.json --output out --model MODEL_ID
```

Keep the API key in the environment. Do not commit it or embed it in generated HTML.
